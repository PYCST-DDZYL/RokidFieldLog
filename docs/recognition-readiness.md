# 自动识别：范围与验收条件

更新：2026-10-13。用户现在允许增加 AI 识别，替代最初“第一版不做 AI”的限制。照片本机处理、无自建云服务／账户、人工核对以及私有存储的要求继续保留。

## 当前可用能力

眼镜支持人工快捷标签：待确认、坑洞／路面损坏、设施损坏、垃圾堆积、其他问题。选择作用于本次打开 App 后的后续拍照，直到重新选择；重开 App 默认待确认。每张照片记录自己的选择快照，保留到元数据。

人工选择不是模型识别。记录保存 issueCategorySource=USER_TAGGED、issueCategoryNeedsReview=true、recognitionStatus=NOT_RUN；没有计算或展示虚构的识别置信度。这些标签也不能直接当作已经核对过的训练集真值。

**当前没有接入经过验收的问题识别模型，识别准确率未测。** 构建通过、相机拍摄成功、文件恢复测试通过，都不能证明模型能正确识别坑洞、设施损坏或垃圾。

## 已核对的候选方案

| 方案 | 已知能力 | 本项目尚缺的条件 |
| --- | --- | --- |
| Google MediaPipe 常规物体检测模型 | 官方默认模型使用 COCO 固定类别；支持自定义 TFLite 模型和类别元数据 | 通用物体类别与“设施是否损坏”等问题分类不同，需针对目标问题训练和评测 |
| OpenAI CLIP／公开 ONNX 转换模型 | 图像与固定英文文本候选之间的相似度；可离线运行的技术路线 | 原始模型卡要求严格的领域与类别测试；相似度不能直接当作本项目的准确率或校准概率 |
| Sekilab RoadDamageDetector / RDD | 研究者发布道路裂缝、坑洞数据及移动模型；部分数据来自车载手机 | 与步行眼镜的视角存在差异；不覆盖全部设施损坏和垃圾；模型转换、分发许可、眼镜实拍评测仍需核对 |

眼镜只读检测为 arm64-v8a，同时支持 32 位 ABI，物理内存约 1.8 GB。不能把需要大内存的视觉大模型默认放进眼镜。后续优先评估手机本地识别；手机当前未连接，具体兼容性与耗时尚未实测。

模型资料和实际 SDK 二进制审阅文件仅留在忽略的 .local；没有上传现场照片、个人坐标或模型授权凭据。

## 发布自动识别前的验收

1. 明确模型支持的类别、许可、版本、校验值和输入预处理；未覆盖的类别返回“不确定”。
2. 使用已人工核对的真实现场照片，包括正常路面／完整设施等负样本，以及低光、运动模糊和易混淆场景。
3. 按地点和拍摄批次分开训练、调参与验收集，避免同一场景反复拍摄造成数据泄漏。
4. 分类别记录 precision、recall、误报／漏报、拒绝识别率及测试样本量；未经该验收，准确率写“未测”。
5. 在实际目标手机／眼镜上检查耗时、内存、取消、失败和连续拍摄；照片保存与定位流程不依赖识别成功。
6. AI 仅提供需人工确认的候选类别，保留原始输出与人工修订来源。问题实际位置仍需地图确认。

不能承诺所有图片都识别正确。实际目标应是可测量的误报／漏报控制，以及在信息不足时可靠地保留“不确定”，由用户确认最终报告。
