# Phase 3 坐标和照片隐私设计

当前离线预览已实现手动问题坐标、手动画框、实际 JPG 审阅和通用人工提交材料导出；操作见 [离线整理](offline-companion.md)。地图、坐标转换、自动检测和具体渠道适配仍待实现。本页保留地图接入时的要求。

## 坐标流转

| 步骤 | 数据与坐标系 | 转换发生的位置 |
| --- | --- | --- |
| 手机采集 / Phase 2 传输 | 原始 phoneLocation 为 WGS84，保留时间、精度、来源 | 原始数据不转换，跨设备传输不改写 |
| 国内地图显示 | 高德/腾讯采用相应 SDK 要求的 GCJ02；百度默认采用 BD09，或按其全局设置使用 GCJ02 | 手机地图适配器调用已选厂商官方转换接口；每次显式检查输入/输出 CRS，转换后的显示点独立保存 |
| 人工修正问题点 | issueLocation 存地图回调实际输出的坐标及 coordinateSystem；另存人工确认信息和文字地址 | 不把人工修正点覆盖到原始 phoneLocation，不把地图点直接标为 WGS84 |
| 渠道导出 | 使用渠道配置要求的坐标系；仅文字地址的渠道导出确认后的地址 | 导出适配器按源/目标系转换一次；缺少已验证的转换路径或 CRS 时阻止坐标导出 |

旧记录的 issueLocation 缺失坐标系时保留未知（null），不能猜成 WGS84。不要用屏幕显示点再次转换，也不要把不同坐标系的经纬度直接比较。[高德官方坐标转换](https://lbs.amap.com/api/lightweight-android-sdk/guide/computing-equipment/coordinate-transformation)、[腾讯地图坐标约定](https://github.com/TencentLBS/tencentmap-miniprogram-skill/blob/main/quick_start_and_best_practices.md)、[百度 Android 坐标说明](https://lbsyun.baidu.com/docs/android?title=androidsdk%2Fguide%2Ftool%2Fcoordinate)明确了转换接口和 SDK 坐标类型；SDK 版本选定后再核对实际签名。

国内发布优先选有资质的地图服务商与有审图号的底图，按供应商说明显示归属与审图号；记录供应商、SDK 版本和地图审核信息。[《地图管理条例》第二十二条、第三十三条](https://www.gov.cn/zhengce/zhengceku/2015-12/14/content_10403.htm)规定审图号标注和相关互联网地图服务资质。V1 不采用未经适用性核验的 OSM 在线瓦片；是否另需送审根据实际产品形式核实。

验收采用明显区分 CRS 的合成测试点、厂商官方转换示例及若干现场已知地标：同源同目标不转换，WGS84→地图→人工修正→同系导出不重复偏移，海外和厂商覆盖范围按其规定处理。不得只看点“在附近”就认定正确；同时单独评估 GPS 精度和人工落点误差。原始坐标和转换来源必须可追溯。

## 照片隐私

[《个人信息保护法》](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)强调处理目的、必要范围与相关告知要求；可识别第三方的街景内容需在产品流程中处理。本项目默认采集公共设施问题，避免无关人脸、车牌、住址门牌和室内场景。具体政务取证要求仍以所选渠道为准。

当前离线预览的导出流程依次为：选择事项 → 确认地址/分类/事发日期 → 本地检查第三方信息 → 在副本上打码 → 生成方向归一化、压缩和清理元数据后的副本 → 用户检查实际输出照片 → 检查大小和可读性 → 用户选择保存材料包。原始照片留在私有存储，打码和压缩只处理派生副本，派生文件另算指纹并记录原图关联。

先提供手动画框并用不透明遮挡覆盖的本地工具；后续人脸/车牌检测只是候选框，允许补框和调整，漏检不应导致自动通过。导出后重新打开实际输出文件检查遮挡，禁止导出原图路径或只保存界面覆盖层。副本删除 GPS、设备标识和无关 EXIF，方向归一化后保持正确显示；地址和联系信息只在所选渠道需要时导出。

记录 privacyReviewStatus 默认 NOT_REVIEWED；没有完成逐张审阅、第三方信息处理或清晰度确认时阻止导出。即使没有识别到人脸，也不能自动改成已审阅。文件内容发生变化时撤销审阅状态并重新审核；保留/删除原图与派生文件的选项要明确。

验收用授权或合成人脸/车牌、远处小目标、反光、遮挡和斜拍测试图；检查导出文件本身的遮挡像素、EXIF、大小、照片与记录的对应关系，确认无原图泄漏。当前离线草稿使用独立 PhotoReview 绑定原图和副本，源记录的 privacyReviewStatus 不被改写为已审阅。电脑测试检查合成 JPEG 的实际遮挡像素和元数据/指纹门禁；Android 渲染器的八种 EXIF 方向、缩放交互、文件选择器和真实拍摄内容仍需设备验收。
