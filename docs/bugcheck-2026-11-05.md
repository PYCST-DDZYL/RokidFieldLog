## 修改内容

- 手机读取最近一次定位与最近成功定位时，先验证原始 JSON，再交给 Android JSON 对象。成功历史必须通过原有的坐标、精度、来源、模拟位置和时间字段校验；失败及取消记录仍用于诊断，不能提供参考坐标。
- 新增回归覆盖重复状态与模拟位置字段、带小数点的整数写法、未知或类型错误的状态、缺少位置的成功记录，以及正常历史和未知标注的保留。
- 手机预览旋转、缩放或创建隐私副本失败时，释放当前持有的位图；创建绘制副本失败时也释放源预览。成功返回的位图交给调用方继续使用。
- 手机为 code 24 / `0.7.16-probe-history`，眼镜为 code 16 / `0.2.13-maintenance`。

Android 的 `JSONObject.numberToString` 对可表示为整数的数值使用整数文本输出。本项目原有的部分格式校验发生在 JSON 对象重新序列化之后，可能丢失原始数字写法的区别，因此把校验提前到读取原文的入口。[Android 官方实现](https://android.googlesource.com/platform/libcore/+/refs/heads/main/json/src/main/java/org/json/JSONObject.java)

## 真机复测

1. 户外运行自动定位与 Android 系统定位，分别查看本次结果和重新打开页面后的历史结果。
2. 成功定位后取消下一次请求，再从材料页选用最近成功的历史参考位置，核对来源、坐标和时间。
3. 在隐私审阅与复查对照页反复打开带旋转方向的 JPEG、缩放并返回，检查照片方向和显示。
4. 在读取照片期间返回或旋转页面，再打开检查，观察异常提示与内存表现。
