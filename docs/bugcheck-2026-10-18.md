# 异常检查与复测（2026-10-18）

本轮检查定位历史、隐私确认和草稿兼容。未安装或操作手机/眼镜，也未删除设备上的任何数据。异常 JSON 和图片全部为项目内合成夹具。

## 发现及修改

| 问题 | 修复 |
| --- | --- |
| 定位页面以坐标对象存在作为成功条件 | 显示与参考位置选用共用 `CaptureRecordCodec.referenceFromProbe`。必须为 schema 1、SUCCESS、受支持的定位来源/权限、明确的非模拟结果，且坐标、坐标系、时间、精度和保存的回调数据年龄有效 |
| 历史定位的缺失模拟标记默认 false，部分数字被转换 | 缺失/null/字符串模拟标记、小数时间、字符串坐标或精度、过期或未知回调年龄均不采用。历史参考位置仍保留原定位时间，不能证明当前位置或拍摄时位置 |
| JSON 字符串确认可能被当成用户确认 | 草稿的地址确认、演示标记、隐私声明必须为实际布尔值，防止 `"true"` 被解释成完成确认 |
| 版本/图片信息截断、未知字段被丢弃 | 版本、尺寸、字节数、审阅时间严格检查整数与范围；未来草稿/审阅/问题坐标字段使旧版本停止编辑并保留原文件 |
| 遮挡框缺少边界时补默认值 | 必须明确提供四个数值边界；已有范围和非空校验继续生效，不推测遮挡范围 |

完整旧草稿与安全的省略默认字段继续支持；真正的零坐标、未知精度、近似权限和系统定位仍有测试覆盖。损坏数据不会自动改写成“正常”，原图和审阅副本保留。
