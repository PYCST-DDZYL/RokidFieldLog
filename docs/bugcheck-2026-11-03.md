# 导入、导出、定位和发布检查

日期为 2026-11-03。测试使用项目内的合成照片、坐标和隔离 Git 仓库。源码单独分批推送到 GitHub，签名密钥、私人数据、构建缓存和 APK 保留在项目内的忽略目录。

## 修改内容

- 拍摄期间即使只回拨一毫秒，也记录为墙上时钟跳变，仍保留由设备单调时钟测量的拍摄耗时。
- 新定位请求可以从取消回调发起。保留最新请求的所有权，避免过期回调覆盖结果或留下未取消的订阅。
- 手机使用系统选择器导出时，目标成功写入并关闭后，读取临时源文件的关闭异常不会删除已经保存的报告。目标写入或关闭失败时，继续尝试清理部分文件。
- 采集包记录使用严格 UTF-8，格式字段必须是指定字符串。损坏包以及同编号却有不同演示标记的批次均会被拒绝，保留已导入的照片和编辑。
- 手机单图及多图报告、眼镜采集包都对实际写入 ZIP 的照片字节校验大小和 SHA-256，写入时发生变化会使该次导出失败。指纹只用于检测内容变化。
- 发布扫描拦截签名容器、定位记录与恢复副本，也检查紧凑 JSON 中可识别的经纬度字段。检查针对 Git 暂存内容，命中时隐藏文件内容。

## 真机复测

1. 在眼镜连拍并导出采集包，用 Android Companion 导入。重新导入同一包，核对重复计数和已有手工编辑。
2. 在手机预览并导出单图与多图报告，用系统文件选择器保存到自己的测试目录，打开 ZIP 检查照片和说明。
3. 在手机户外运行自动定位和系统定位。快速停止并重新开始，核对屏幕只显示当前请求的结果。关闭定位权限时应出现失败提示，不生成坐标。
4. 参考位置继续由用户明确选用。拍摄者位置、问题实际位置及定位时间分别核对。

这些真机步骤本轮尚未执行。手机独立定位与跨设备拍摄关联是两个测试项，当前包沿用手动转存和历史定位参考。

## 在电脑上重跑检查

在项目根目录用 PowerShell 执行以下命令。执行策略参数只作用于启动的进程。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Test-ToolEnvironment.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Test-PublishSafetyRegression.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Test-PublishSafety.ps1 -AllTracked
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/Build.ps1 -Release -Verify -Clean
```

发布构建使用已有固定签名。新贡献者可先运行 `scripts/Build.ps1 -Verify` 验证调试包。
