# 连续观察与维修复查预览

本轮把一处问题的多次观察、维修反馈和人工复查接成独立历史。问题关联与复查判断均由人完成；没有视觉自动匹配、自动识别或自动验收。当前清单只覆盖已登记的问题，未拍到、未登记或未有效观察的区域没有状态结论。

## 直接使用

1. 手机首页进入“问题历史与待复查清单”。可以按位置/编号搜索，或勾选“只看待复查”。清单每页 30 项，历史最近在前、每页 20 条，避免一次建立大量界面。仍待维修的问题也保留在完整列表。
2. 从照片记录选择“关联问题 / 添加本次观察”，或在问题清单选择“添加问题 / 关联观察照片”。填写明确的位置名称、类别、人工确认的观察日期，并查看照片后确认。首张观察须清晰显示问题，将获得稳定 issueId。
3. 再次经过时导入另一张现场照片，选择原问题，确认位置与日期，分别选择照片可见情况和观察结果。每张记录只关联一个问题；同一问题中指纹完全相同的照片不能换编号当作新观察。GPS 不用于自动合并。
4. 收到维修方反馈后，在问题详情“记录维修反馈”。保存进入待复查，反馈本身没有现场复查效力。原照片的政务回执状态与问题复查状态彼此独立。
5. 反馈之后关联新的复查照片，再打开“前后照片对照”。可分别缩放、拖动最初观察和最近观察，核对同一位置、视野、遮挡、原问题及拍摄先后。填写结论依据后，选择已处理、仍存在或无法确认。
6. 确认已处理必须有最近维修反馈之后登记的新观察：位置清楚、可见范围内未见原问题，并明确由人确认照片拍摄先后。设备时钟和登记顺序不能代替现场时间确认。无法判断时保留待复查，重新观察。

日期必须由人确认，按日期先后追加；同一天的照片依赖人工确认先后顺序。历史以追加事件保存，不改写已有观察和结论。新的问题照片会让曾复查确认的问题重新成为待处理；新的遮挡/无效观察进入待复查。历史确认只描述当次可见范围，不代表以后始终正常。

## 演示

首页“载入复查流程演示”生成三张显著标记的合成图片：破损、遮挡、处理后。它建立问题并记录维修反馈和遮挡观察，停在“需要再次观察”。第三张仍在记录库中，供练习：关联该照片 → 位置清楚可见 → 可见范围内未见原问题 → 前后对照 → 勾选位置/拍摄先后并填写依据 → 人工确认。所有记录与问题持续保留演示标记。

电脑运行测试加 -PfieldlogDemo=true 后，被忽略的 .local/offline-preview/inspection-demo.html 可直接在浏览器打开。五步交互使用真实核心状态规则和合成 JPEG，另外生成 SYNTHETIC-inspection-captures.zip 和 SYNTHETIC-inspection-history.json。HTML 不是 Android 界面截图；历史 JSON 是供检查的合成输出，当前 App 不提供历史 JSON 导入。采集 ZIP 可作为照片导入。

## 证据与删除

观察绑定照片记录 ID 和导入时 SHA-256。关联时校验所选原图；对照与保存人工结论时重新核验最初/最近两张原图。演示与真实资料禁止混入同一问题。指纹用于发现字节改变，不能验证曝光时间、地点真实性或人的判断。

已经关联的照片不能单独删除。可以确认“删除此问题的跟踪历史”后再管理各张照片；删除跟踪保留原照片记录。清除演示会先删除合成问题历史，再清理合成照片。历史损坏时保留原文件、继续显示可读问题，暂停新关联与单张照片删除，避免把未知关联删掉。定位检查页的全项目删除仍覆盖本 App 的全部私有资料，必须经用户确认。

对照只在本机展示原图，未生成新的对外共享入口。需要对外提交时，继续使用每张记录原有的隐私遮挡与材料导出流程；当前没有完整问题历史/多照片政务材料导出。

## 存储与边界

fieldlog-core 定义 TrackedIssue、InspectionEvent 和严格的 InspectionCodec，Android 使用 AtomicFile 在 files/fieldlog/offline/issues/<issueId>.json 保存。修订号与事件数一致，每次追加带预期修订号；旧页面与旧对照不能覆盖新观察。所有操作与记录删除共用进程拥有的后台队列。

列表只读取元数据，不批量解码或计算照片指纹。校验、对照解码、保存与删除均在后台进行。每份历史上限为 1000 个事件或 1 MiB，以先到者为准；超出不写入、不截断历史。未来版本或未知历史字段拒绝改写并保留，防止新字段被旧版本悄悄丢弃。

JVM 测试覆盖反馈不闭环、遮挡/错视角、重复 ID/重复字节、日期与顺序、旧页面、证据改变、再次出现、演示隔离、删除保护、格式异常以及真实导入库与复查仓库联动。Android 实际布局、旋转、照片方向、手势和现场效率尚需设备验收；本轮不连接手机，不声称十倍效率或付费客户已经得到验证。
