四个人工标签属于项目快捷标签，不是政务分类。ROAD_DAMAGE 需在当地查找“道路养护/路面破损”；DAMAGED_FACILITY 必须先明确设施种类，可能归“井盖破损/公共设施”；LITTER 查“环境卫生/垃圾堆积”；OTHER 必须人工选当地分类。以上只是检索方向，不存作真实分类编码；上海农村垃圾渠道不能泛化为全国市政渠道。

Phase 2 开工前，维护者为一个目标地区完成渠道配置：官方入口、受理地域/事项、必填字段与字数、联系方式及告知要求、分类编码和映射、图片类型/张数/单张与总大小/尺寸、是否接受脱敏副本、坐标系或仅文字地址、回执方式、配置核实日期。未核实的上限保持 null，不能套用江苏限制。优先验证无需后台合作即可手动提交的当地 12345。

Phase 3 按该配置倒推导出：说明文本（地址、事项、请求、人工确认的事发日期）、已审阅并打码的 JPG 副本，以及独立记录清单。每个事项单独组包；JSON/CSV 是项目归档格式，未经核实不得称为政务平台导入格式。压缩副本逐张检测实际字节数和清晰度，超限继续缩放/压缩，禁止静默丢图。渠道只接受现场拍摄或拒绝打码副本时先阻止该导出路径，重新选择适用渠道。

验收：使用有权登录的当地账号查看完整表单；用无第三方信息的测试材料验证输入和附件边界，不发送虚假政务投诉；经用户核对实际事项后手动提交一次，私下留存回执和字段版本。上述验收尚未完成。
